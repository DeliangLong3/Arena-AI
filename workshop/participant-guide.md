# Participant guide

## Tasks

1. Read the package map and locate the official examples for SDTM, ADSL, ADRS, ADTTE and TLG.
2. Run the synthetic source-contract check.
3. Inspect one source field that is not CDISC-shaped.
4. Approve or reject one mapping candidate; do not edit it silently.
5. Run the SDTM step and inspect DM, AE or RS.
6. Run the ADaM step and trace one variable into ADSL, ADAE, ADRS or ADTTE.
7. Generate one table, one listing and one figure.
8. Change one source value in a copy of the fixture and identify the affected downstream artifacts.
9. Run from a clean state and inspect the manifest.
10. Ask the AI assistant to explain a function, then verify the explanation against the official documentation.
