# Pinned upstream examples

The classroom uses official pharmaverse examples as the API reference. The revision is recorded in `config/upstream.yml` and must be rechecked during rehearsal.

## Recommended examples

- Overview: <https://pharmaverse.github.io/examples/>
- SDTM overview: <https://pharmaverse.github.io/examples/sdtm/>
- DM: <https://pharmaverse.github.io/examples/sdtm/dm.html>
- ADSL: <https://pharmaverse.github.io/examples/adam/adsl.html>
- ADRS: <https://pharmaverse.github.io/examples/adam/adrs.html>
- ADTTE: <https://pharmaverse.github.io/examples/adam/adtte.html>
- TLG overview: <https://pharmaverse.github.io/examples/tlg/>

## Live selection

Use DM, ADSL, ADRS, ADTTE and one classic `rtables`/`tern` TLG example. Do not open the PK examples in this workshop.

## Why direct TFL

The project scope explicitly excludes ARS/ARD. The TLG section documents both approaches; this workshop selects the classic direct-summarization path for the live run. This is a scope decision, not a claim that ARD is unimportant.
